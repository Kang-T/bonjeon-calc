# 본전 계산기

팔고 다시 사면 **실제 본전가**가 얼마가 되는지 계산하는 개인용 웹앱(PWA).

- 실제 본전가 = (넣은 원금 − 손에 쥔 현금) ÷ 보유 주식 수 ÷ (1 − 매도 비용)
- 증권사 평단은 부분 매도 뒤 이미 판 주식의 손익을 빼고 보여 주므로 실제 본전가보다 낮게 보인다.
- 입력값과 거래 기록은 **이 기기의 브라우저(localStorage)에만** 저장된다. 서버로 아무것도 보내지 않는다.

투자 자문이 아닌 산술 도구입니다.

## 차트 데이터

- `data/<종목코드>.json` — 일봉(6개월)·1시간봉·30분봉. 주가 숫자만 들어 있다.
- 맥북의 수집기(`~/bonjeon-feed/`, 이 저장소 밖)가 평일 09:10~15:40 30분마다(맥 launchd) 토스증권 Open API에서 받아 올린다.
- 앱에서 화면을 위로 당기면 최신 파일을 다시 받는다.
  토스 API 키는 수집기 폴더의 `.env`에만 있고 이 저장소에는 없다.
- 자동 선 = 6개월 일봉 거래량이 가장 많이 몰린 가격 3곳 + 최근 60거래일 최고·최저. 산술일 뿐 매매 신호가 아니다.
